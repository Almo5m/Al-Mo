# ربط إشعارات تليجرام

الإشعارات بتوصلك على تليجرام لما زائر يبعت فورم التواصل أو يبعت طلبه من الرفيق. بوت تليجرام بيبعتلك أنت بس، ومفيش زائر بيتعامل معاه.

ده غير زر "تليجرام" اللي الزائر بيدوس عليه في قسم التواصل، ده رابط لحساب أو قناة (في `src/config.ts`) والزائر بيكلمك منه.

## الخطوات

1. **أنشئ البوت.** في تليجرام ابحث عن `@BotFather` وابعتله `/newbot`. اكتب اسم للبوت (مثلًا AL MO Requests)، ثم يوزرنيم لازم ينتهي بـ `bot` (مثلًا `almo_requests_bot`). هيرجعلك **التوكن**، شكله `123456789:AAH...`.
2. **ابعت للبوت رسالة.** افتح البوت الجديد واضغط Start واكتب أي كلمة. لازم تعمل ده الأول، لأن البوت مش بيقدر يبعتلك قبل ما تبدأ معاه.
3. **هات الـ Chat ID.** افتح في المتصفح (غيّر `TOKEN`):
   `https://api.telegram.org/botTOKEN/getUpdates`
   دوّر على `"chat":{"id":` والرقم اللي بعدها هو `TELEGRAM_CHAT_ID`. لو بتبعت لجروب: ضيف البوت للجروب، ابعت رسالة فيه، وكرر الخطوة دي، والرقم هيبقى سالب (يبدأ بـ -100).
4. **جرّب البوت مباشرة** من الطرفية قبل ما تربطه بالموقع:
   ```bash
   curl -s "https://api.telegram.org/botTOKEN/sendMessage" \
     -d chat_id=CHAT_ID -d text="تجربة من AL MO"
   ```
   لو وصلتك الرسالة، التوكن والـ Chat ID صح.
5. **حطهم في Supabase:**
   ```bash
   supabase secrets set TELEGRAM_BOT_TOKEN=التوكن TELEGRAM_CHAT_ID=الرقم
   ```
   أو من لوحة Supabase: Edge Functions → Secrets.
6. **انشر الدالتين** (ملف الإشعارات اتعدّل):
   ```bash
   supabase functions deploy contact
   supabase functions deploy companion
   ```
7. **جرّب من الموقع:** ابعت رسالة من الفورم. المفروض توصلك على تليجرام خلال ثواني. (الفورم بيسمح بـ 3 رسائل في الساعة لكل زائر.)

## لو مش بتوصل
افتح Supabase → Edge Functions → contact → Logs. هتلاقي سطر بيبدأ بـ "تليجرام":

| السطر في اللوج | المعنى والحل |
|---|---|
| `مش متحطين في أسرار Supabase` | الأسرار مش متضافة. كرر الخطوة 5 |
| `فشل: 401` | التوكن غلط |
| `فشل: 400 ... chat not found` | الـ Chat ID غلط، أو ما ضغطتش Start على البوت |
| `فشل: 403` | حظرت البوت أو اتشال من الجروب |
| مفيش سطر وبرضو مش بتوصل | الدالة نفسها بتفشل قبل الإشعار. شوف باقي اللوج، وراجع `docs/companion-demo-mode.md` |

## الأمان
- التوكن سر: متحطوش في GitHub ولا في الشات ولا في أي ملف في الواجهة. مكانه الوحيد أسرار Supabase.
- لو اتسرّب: في `@BotFather` ابعت `/revoke` واختار البوت، وحط التوكن الجديد في Supabase.
- الدالة بتبعت نص عادي من غير تنسيق ومن غير معاينة روابط، لأن الزائر هو اللي كاتب النص.
- التوكن مش بيتكتب في اللوج حتى لو الاتصال فشل.
