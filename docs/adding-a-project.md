# إزاي تضيف مشروع جديد للموقع

## اللي محتاجه من كل مشروع
1. **الاسم** (بالعربي والإنجليزي).
2. **وصف قصير**: جملة أو اتنين بتقول المشروع بيعمل إيه.
3. **الأثر أو النتيجة**: حاجة حقيقية ومقدرة تثبتها (ميزة مميزة أو نتيجة فعلية). ممنوع أرقام مخترعة.
4. **التقنيات**: 3 أو 4 تاجات (مثلًا React وSupabase).
5. **رابط الديمو** (لو فيه). لازم يكون ببيانات تجريبية، ولازم يسمح بالتضمين في iframe.
6. **لقطة شاشة** بنسبة قريبة من 16:9 وعرض 1280 تقريبًا، بتبيّن أهم شاشة (الواجهة الأهم فوق).

## أماكن التعديل
- `src/i18n/sections.ts`:
  - في `PROJECTS_DATA`: سطر جديد (`id` + `tags` + `demoUrl` + `preview`).
  - في `PROJECTS`: النصوص (`title` و`desc` و`impact`) بالعربي وبالإنجليزي، **بنفس ترتيب** `PROJECTS_DATA`.
- `public/projects/`: حط لقطة الشاشة (webp أو jpg). مسارها في `preview`.
- `vercel.json`: لو دومين الديمو جديد، ضيفه في `frame-src` (شوف `docs/security-headers.md`).
- `supabase/functions/companion/persona.ts`: في قسم "الأعمال"، ضيف سطور عن المشروع الجديد عشان الرفيق يعرفه (من معلومات حقيقية بس)، وبعدها `supabase functions deploy companion`.

## نصايح
- لو مفيش ديمو دلوقتي سيب `demoUrl` فاضي، والزر هيكتب "الديمو قريبًا".
- لو مفيش لقطة سيب `preview` فاضي، والمكان هيفضل بالشكل الافتراضي.
- المشاريع بتظهر في شبكة من عمودين، ولو مشروع واحد بس بيتوسّط.
