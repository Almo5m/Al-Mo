# لوحة التحكم (/admin)

لوحة خاصة بيك بس، على `https://موقعك/admin`. فيها:
- **نظرة عامة:** زيارات الموقع ومصادرها وأجهزتها ولغاتها ودولها، وأكتر الأقسام مشاهدة، ومسار الزائر (زار ← شاف المشاريع ← فتح ديمو ← كلّم الرفيق ← بعت طلب).
- **الطلبات:** كل طلبات الفورم والرفيق في مكان واحد، بحالة (جديد، اتقرا، اتردّ عليه، مؤرشف) وملاحظة ليك.
- **الآراء:** تعمل لينك تقييم لكل عميل، والعميل يكتب رأيه، وأنت تقبله أو ترفضه أو تعدّله. اللي تقبله بيظهر في الموقع لوحده.
- **الإعدادات:** استبعاد متصفحك من الإحصائيات، وتنظيف الزيارات القديمة، وتسجيل الخروج.

## الإعداد (مرة واحدة)

1. **ثبّت الحزم** (اتضافت حزمة `@supabase/supabase-js`): `npm install`
2. **شغّل قاعدة البيانات:** افتح Supabase → SQL Editor، والصق محتوى `supabase/migrations/0002_dashboard.sql` وشغّله. (بيضيف جداول الزيارات والآراء وصلاحيات الأدمن، ومش بيمسح أي بيانات موجودة. الطلبات القديمة هتظهر كلها "جديد" أول مرة، علّمها "اتقرا" أو أرشفها.)
3. **اقفل التسجيل:** Supabase → Authentication → Sign In / Providers → اقفل **Allow new users to sign up**. من غير ده أي حد يقدر يعمل حساب.
4. **تأكد إن كود التحقق متفعّل:** Authentication → Multi-factor (أو Sign In / Providers) → التطبيق (TOTP) لازم يبقى Enabled.
5. **اعمل حسابك:** Authentication → Users → Add user → Create new user. اكتب إيميلك وكلمة سر قوية وفريدة (يفضل من مدير كلمات سر)، واختار تأكيد الإيميل تلقائي.
6. **سجّل نفسك أدمن** (من SQL Editor، غيّر الإيميل):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'ايميلك@example.com';
   ```
7. **انشر الدالتين الجداد:**
   ```bash
   supabase functions deploy track
   supabase functions deploy review
   ```
   ولازم `IP_HASH_SALT` يكون متحط في الأسرار (نص عشوائي طويل). لو كان متحط قبل كده مفيش حاجة جديدة. لو مفيش: `supabase secrets set IP_HASH_SALT=نص-عشوائي-طويل`. ولو مفتاحك من نوع `sb_publishable_` انشر بـ `--no-verify-jwt` زي ما في `docs/companion-demo-mode.md`.
8. **ارفع الموقع** (git push) وانتظر Vercel. ملف `vercel.json` فيه المسارات `/admin` و`/review`.
9. **ادخل:** `/admin` ← إيميل وكلمة السر ← أول مرة بيظهر QR، امسحه بتطبيق المصادقة (Google Authenticator أو Authy) واكتب الكود. من المرة الجاية بتكتب الكود الحالي بس.
10. **أول حاجة جوه:** الإعدادات ← فعّل "استبعاد المتصفح ده"، عشان زياراتك ما تتعدش. (برضو لو متصفحك فيه Do Not Track بتتتجاهل لوحدها.)

## الآراء: إزاي بتشتغل
1. الآراء ← "لينك تقييم جديد": اكتب اسم العميل (ليك بس) واسم المشروع (اختياري) والصلاحية، واضغط إنشاء.
2. انسخ اللينك **فورًا** (بيظهر مرة واحدة، ومتخزّن منه الهاش بس) وابعته للعميل. لو ضاع: "تجديد اللينك".
3. العميل بيفتحه، بيكتب اسمه وتقييمه (1 إلى 5) ورأيه (20 حرف على الأقل) ويوافق على العرض. اللينك بيشتغل **مرة واحدة** وبعدها بيتقفل.
4. بيوصلك إشعار على تليجرام وإيميل إن فيه رأي جديد. الرأي بيستنى مراجعتك (مش ظاهر لأي حد).
5. تقبله أو ترفضه. تقدر تعدّل الاسم والوظيفة والنص (تعديلك بيتحفظ منفصل، ورأي العميل الأصلي فاضل زي ما كتبه) والترتيب. وتقدر تخفيه بعد القبول.
6. أول رأي تقبله بيفعّل قسم "آراء العملاء" (ورابطه في القائمة) في الموقع تلقائيًا.

## الزيارات: إيه اللي بنسجّله
- كل زائر بيتحسب **مرة في اليوم** لكل حدث. الهوية هاش بيتغيّر كل يوم (من سر + التاريخ + الـ IP + المتصفح)، والـ IP نفسه **عمره ما بيتخزّن**. فمفيش تتبع للزائر عبر الأيام.
- بنسجّل: الزيارة، الأقسام اللي وصلها (40% منها ظهر)، فتح ديمو، الضغط على قناة تواصل (واتساب/تليجرام/إيميل)، بدء محادثة مع الرفيق، إرسال طلب (فورم أو الرفيق)، وتغيير اللغة.
- مصدر الزيارة: الدومين اللي جيت منه، أو علامة من عندك. لو بعت لينك للموقع بالشكل `https://موقعك/?ref=linkedin` هتظهر في المصادر "لينك: linkedin".
- مفيش كوكيز، وبنحترم Do Not Track وGlobal Privacy Control، ومفيش تتبع على localhost، والبوتات مش بتتعد.
- الدولة بتظهر لو المنصة بعتتها (مش مضمون)، والتواريخ بتوقيت UTC.
- سياسة الخصوصية اتحدثت عشان تذكر ده (لسه مسودة وتحتاج مراجعتك).

## الأمان
- الدخول: إيميل + كلمة سر + كود تحقق. وقاعدة البيانات نفسها بترفض أي قراءة أو تعديل من أي حد مش أدمن داخل بكود التحقق، حتى لو عرف مفتاح `anon` (ده بيظهر في المتصفح بطبيعته).
- كل الجداول مقفولة على الزائر تمامًا. الموقع بيكتب فيها من خلال دوال السيرفر بس، وبحد استخدام.
- صفحتا `/admin` و`/review` مش بتتفهرس في محركات البحث، ولا بتتخزّن.
- لينك التقييم: توكن عشوائي 192 بت، متخزّن هاشه بس، بيشتغل مرة واحدة وله صلاحية، وبيتشال من الرابط في المتصفح أول ما الصفحة تفتح.
- **لو فقدت جهاز المصادقة:** من SQL Editor امسح الكود القديم وسجّل من جديد:
  ```sql
  delete from auth.mfa_factors where user_id = (select id from auth.users where email = 'ايميلك@example.com');
  ```
  وادخل `/admin` تاني، هيطلب منك تفعيل كود جديد. (احتفظ بنسخة من المفتاح السري اللي بيظهر تحت الـ QR في مكان آمن.)

## لو حاجة مش شغالة
| المشكلة | الحل |
|---|---|
| "تعذّر تحميل الإحصائيات" أو الآراء | ملف `0002_dashboard.sql` ما اتشغّلش |
| "تعذّر بدء التفعيل" | كود التحقق (TOTP) مش متفعّل في Supabase Auth |
| "مفيش صلاحية" بعد الدخول | الخطوة 6 (جدول admins) ما اتعملتش، أو الإيميل غلط |
| الزيارات صفر | تأكد إن الدالة `track` منشورة، وإن متصفحك مش Do Not Track أو مستبعد، ومش على localhost. شوف Logs الدالة في Supabase |
| صفحة التقييم "اللينك مش صالح" | اللينك اتستخدم أو انتهى. اعمل تجديد |
| 404 على `/admin` | تأكد إن `vercel.json` اترفع وعملت Redeploy |

## التحكم في المحتوى (المرحلة الجاية)
المشاريع وتشغيل وإيقاف الأقسام وروابط التواصل لسه بتتعدّل من الكود (`docs/adding-a-project.md`). نقلها للوحة هي المرحلة التانية.
